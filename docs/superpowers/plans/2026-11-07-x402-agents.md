# Autonomous x402 Trading Agents Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a trader run many autonomous agents that trade Night Shares room nights on Arc through x402 paid HTTP requests, with a model writing strategy and code executing it, settled atomically on chain.

**Architecture:** Contracts first: `NightToken` gains EIP-3009, a new `X402Settler` pulls an x402 `exact` payment and trades through new settler only `TradeRouter.buyFor` and `sellFor` so identity, cap and fees follow the agent wallet. The API gains an `agent` module (agents, strategist, executor, withdraw), an x402 facilitator and HTTP endpoints, and an outbox that reconciles chain results into SQLite. The Trade app gains agent list, deploy flow and agent detail.

**Tech Stack:** Solidity 0.8.26 (Foundry, via IR, Cancun, Uniswap v4, Permit2, solady), Bun 1.3 + Connect + SQLite + viem, protobuf (buf, protoc-gen-es, connect-query), Next.js App Router, `openai` npm client (OpenAI compatible endpoint).

**Spec:** `app/docs/superpowers/specs/2026-11-07-x402-agents-design.md` (read with `app/SPECS.md`, `app/STANDARDS.md`, `app/packages/contracts/CONTRACTS.md`).

## Global Constraints

- Arc safety limits stay: `MAX_F` 1 USDC (1e6), `MAX_POOL` 50 USDC (50e6), `MAX_S` 100, `MAX_OPEN_NIGHTS` 20. Do not raise them for agents.
- 30% per human cap (`capOf(S) = max(1, 0.3 * S)`) across all of a human's wallets, every agent wallet included.
- Fees unchanged: 1.3% per trade (host 1%, treasury 0.2%, cover fund 0.1%); late sell-back fee to `RebatePool`; a host's own trades (any wallet of its human, agent wallets included) send its 1% to `RebatePool`.
- Protocol pause blocks entries and swaps, never withdrawals from agent wallets.
- Agent Pass threshold: 10 USDC with `CHAIN_LIMITS=mainnet`, 100 USDC otherwise (anvil fork, testnet, mock). `AGENT_APPROVAL_THRESHOLD_USDC` still overrides. Strictly greater than the threshold needs the check. No rolling window.
- Only buys are checked. Sells never need a World ID check.
- Model provider env: `AGENT_LLM_BASE_URL`, `AGENT_LLM_API_KEY`, `AGENT_LLM_MODEL`. Prototype points at Anthropic's OpenAI compatible endpoint; later `https://pc.0g.ai`. No code change between them.
- No secrets in URLs or the browser. Model key, agent keys and operator key stay server side.
- `X402Settler` has no admin, no pause, no withdraw function. Balance checks are per call deltas.
- Money is bigint micro USDC, quantities are integer tenths in TypeScript and multiples of 1e17 on chain.
- Proto first: change `.proto`, run `pnpm gen`, then code. Never hand write generated types.
- Files: soft limit 150 lines, hard limit 250 (STANDARDS). Adapters are `<port>.<impl>.ts`. Every port ships a mock adapter.
- Docs: no em dash and no spaced hyphen as sentence punctuation.
- Git: stage explicit paths only (never `git add -A`, `.` or `-a`). Run `git status --short` first; other sessions share the checkout. No Claude mention or co-author trailer in commit messages. The coordinator runs the commit steps.
- Fork first: everything runs end to end on the anvil fork of Arc mainnet (`docker-compose.chain.yml`, chain 5042) before mainnet. Mainnet deployment is out of scope; only mainnet config defaults ship.
- Canonical sell rationale (use this wording, lightly adapted, in the executor comment, SPECS, `apps/api/README.md`): "Sells never need a World ID check, by design. A sell only turns room nights back into USDC in the agent's own wallet, so it cannot spend the user's money. Holding an exit for approval would trap funds, stop the agent exiting within its limits, and can push the sale into the late sell-back fee window, costing the user up to 30%."

## Review Focus

1. **Facilitator crashes after broadcasting a settle transaction and before recording it.** Expected: on restart the outbox recovers the operation by id, applies the fill once, and never signs a second authorization for the same trade. Pinned in Task 18 (`agent trade survives crash after broadcast and fills once`).
2. **A night reaches cutoff while a paused agent still holds its tokens.** Expected: withdraw-all still completes; the cutoff refund arrives as USDC in the agent wallet (via `pushBatch` or credit withdrawal) and is swept to the user. Pinned in Task 12 (`withdraw all after cutoff sweeps the refund`).
3. **The user's own wallet is not linked in `HumanRegistry` on chain.** Expected: agent creation links both the user wallet and the agent wallet to the same `humanId`, so a paused withdrawal of room nights never reverts `UnverifiedHuman`. Pinned in Task 11 (`create agent links user and agent wallets on chain`).
4. **Two agents of one human target the same night in the same tick.** Expected: the pre-check sums reservations across all of that human's agents, so at most the cap is planned; an on chain `CapExceeded` revert is classed as a limit failure and never retried. Pinned in Task 17 (`two agents never plan past the shared cap`).
5. **The pool moves between the 402 quote and settlement.** Expected: authorization value is quote plus one micro per tenth; any unused part is refunded in the same transaction; a `Slippage` revert costs nothing, is not a limit failure, and the next tick re-quotes. Pinned in Task 17 (`price move reverts without payment and re-quotes`).

**Interfaces:**
- Consumes: `ITradeRouter.buyFor/sellFor` (Task 4), `IERC3009` (Task 3), MockUSDC EIP-3009 (Task 1).
- Produces `IX402Settler`:
  - `struct Authorization { address from; address to; uint256 value; uint256 validAfter; uint256 validBefore; bytes32 nonce; }`
  - `buy(Authorization calldata auth, bytes calldata signature, bytes32 night, uint256 qty, Ask[] calldata asks, Hint[] calldata hints, uint64 deadline, bytes32 salt) external returns (uint256 paid)`. `auth.value` is the maximum paid.
  - `sell(Authorization calldata auth, bytes calldata signature, bytes32 night, uint256 minReceived, Hint[] calldata hints, uint64 deadline, bytes32 salt) external returns (uint256 received)`. `auth.value` is the token quantity.
  - `refundUnused(address token, Authorization calldata auth, bytes calldata signature) external`
  - `buyNonce(bytes32 night, uint256 qty, uint64 deadline, bytes32 salt) external pure returns (bytes32)` = `keccak256(abi.encode(keccak256("X402Buy(bytes32 night,uint256 qty,uint64 deadline,bytes32 salt)"), night, qty, deadline, salt))`
  - `sellNonce(bytes32 night, uint256 minReceived, uint64 deadline, bytes32 salt) external pure returns (bytes32)` with type string `"X402Sell(bytes32 night,uint256 minReceived,uint64 deadline,bytes32 salt)"`
  - `processed(address token, address from, bytes32 nonce) external view returns (bool)`
  - events `X402Bought(bytes32 indexed night, address indexed payer, bytes32 nonce, uint256 qty, uint256 paid, uint256 refunded)`, `X402Sold(bytes32 indexed night, address indexed payer, bytes32 nonce, uint256 qty, uint256 received)`, `UnusedRefunded(address indexed token, address indexed from, bytes32 nonce, uint256 value)`
  - errors `NotSettlerPayment()` (auth.to not this), `TermsMismatch()` (nonce not bound to the call terms), `DeltaMismatch()`, `AlreadyProcessed()`, `NotUsed()`.
- Rules: anyone may call `buy`/`sell` (the terms bound nonce means a relayer cannot change night, qty, minimum or deadline; asks can only change which fills occur under `auth.value`). Each call records `before` balances of itself and requires the pulled delta to equal `auth.value` and its own end balance to equal `before`. `buy` marks `processed`, calls `buyFor(auth.from, ...)`, refunds `auth.value - paid` to `auth.from`. `sell` marks `processed`, approves exactly `auth.value`, calls `sellFor(auth.from, ...)` and requires `received >= minReceived`. `refundUnused` requires `auth.to == this`, `!processed`, `IERC3009(token).authorizationState(auth.from, auth.nonce)`, a valid `auth.from` signature over `token.DOMAIN_SEPARATOR()`, then marks processed and transfers `auth.value` to `auth.from`. Constructor approves USDC `type(uint256).max` to `tradeRouter`. Reentrancy guard on all three. No owner.
